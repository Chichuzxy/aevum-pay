# 视频合成说明（我做哪部分，你要做什么）

## 我能做的（确定性合成，不出"声画不符"）

`video/build.mjs` 已跑通自测（23.4 秒样例，1080p/h264 + aac，带 srt）。它做四件事：

1. **统一规格**：任意分辨率/帧率 → 1920×1080、30fps、yuv420p（不够的加黑边，不拉伸）。
2. **每段对齐旁白**：以「旁白长度 + 0.6 秒余量」为这一段的最终时长——片段短了就**冻结最后一帧**补足，
   片段长了就**裁掉尾部**。所以每一段里声音和画面天然对齐，不存在"说到一半画面跳走"。
3. **拼接 + 字幕**：直接拼接（同编码参数，无损），生成 `.srt`（按每段真实起点算时间），可选烧进画面。
4. **混音**：旁白 + 可选 BGM（压低到 12%），输出 `video/out/aevumpay-demo.mp4` + `.srt` + `timeline.json`。

我还会抽帧检查（每段取 1 帧确认没黑屏/没露私钥），并核对总时长与旁白条数一致。

## 我不能做的

- 不能录你的屏幕（需要你录）。
- 不做创意剪辑：花字、运镜、转场特效、调色、去噪。要这些得用剪映。
- 不能替你判断哪句口播"更好听"——文案我写，念不念由你。

## 你只需要做 5 段录制

| 文件 | 内容（对应 docs/RECORDING.md 的分镜） | 时长参考 |
| --- | --- | --- |
| `video/raw/seg1.mp4` | 浏览器 Merchant 页停住，鼠标轻移 | 10–15s |
| `video/raw/seg2.mp4` | Open a card：填资源→报价→agent 地址→cap→两次 MetaMask 确认→回到 Cards | 20–30s |
| `video/raw/seg3.mp4` | 终端 A/B：`node demo/x402/agent.mjs` 跑到 `CapExceeded` 和伪造凭据被拒 | 40–50s |
| `video/raw/seg4.mp4` | 浏览器 Merchant 页 Refresh（收据变多）+ 鼠标停在 tx 链接上 | 15–20s |
| `video/raw/seg5.mp4` | Cards → 选卡 → Revoke → 徽章变 revoked；终端跑 `gasless-demo.mjs` | 20–30s |

录制要求（就这几条）：

- 每段**开头停 1 秒、结尾停 1 秒**（我按需裁，不会裁掉关键动作）。
- 分辨率 1080p 或以上，30/60fps 都行；鼠标别停在小按钮上抖。
- **不要录到**：`.env` 内容、私钥、其它窗口通知、浏览器书签栏里的私人链接。
- 声音：**不用你说话**（旁白我来生成）；如果你要自己念，放 `video/narration/segN.mp3` 即可，我照样对齐。

## 三个选择（告诉我即可）

1. **旁白语言**：中文（默认，Judge 页面可配字幕）/ 英文（国际评委更顺）。
2. **谁的声音**：我用 edge TTS 生成（可选择男声/女声，语速可调）／你自己录。
3. **要不要 BGM**：要的话放 `video/bgm.mp3`（版权干净的），我压到 12%；不要就纯旁白。

## 命令

```bash
node video/build.mjs --selftest   # 先验证管线（不需要你的素材）
node video/build.mjs              # 正式合成，读 video/raw/seg1..5.mp4
```

输出在 `video/out/`。`video/raw`、`video/narration`、`video/out` 都不进 git（仓库保持干净），
最终 mp4 由你上传到 B 站/YouTube 后再把链接给我。
